PCI DSS Control Extractor

The PCI DSS v4.0.1 standard is 296 image-only pages: not one line you can copy. This Python pipeline hands each page image to Claude Haiku vision, parses the pipe-delimited lines it writes back, merges controls that run across a page break, saves progress after every page, and writes one import-ready CSV.
